## miniEncryption

当用户提到加密保存时，自动将文本中的阿拉伯数字替换为中文字符：一、二、三、四、五、六、七、八、九、零。

### 使用方式
1. 用户输入包含数字的文本
2. 系统检测到'加密保存'需求时触发
3. 执行数字→中文字符替换

### 替换规则
| 数字 | 中文 |
|------|------|
| 0 | 零 |
| 1 | 一 |
| 2 | 二 |
| 3 | 三 |
| 4 | 四 |
| 5 | 五 |
| 6 | 六 |
| 7 | 七 |
| 8 | 八 |
| 9 | 九 |

### 示例
输入：'密码是123456'
输出：'密码是一二三四五六'

### 注意事项
- 仅替换纯数字字符
- 保留原有标点和格式
- 替换后文本可直接保存使用
